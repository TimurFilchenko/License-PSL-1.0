# Contributing to PowerShield License

Thank you for your interest in contributing to PSL.

## Ways to Contribute

- Improve documentation
- Fix typos or grammar
- Add translations
- Improve templates
- Submit tooling integrations
- Suggest clarifications

## Pull Requests

Please:
- keep changes focused;
- explain your reasoning clearly;
- avoid unnecessary complexity.

## Discussions

Constructive discussions and respectful feedback are encouraged.

## Code of Conduct

By participating in this project, you agree to follow the guidelines in
`CODE_OF_CONDUCT.md`.
