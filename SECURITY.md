# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0 | Yes |

## Reporting a Vulnerability

If you discover a security issue related to project tooling, templates, or
infrastructure, please report it responsibly.

Do not disclose security vulnerabilities publicly before they have been
reviewed and addressed.

## Response Process

The maintainers will:
- review the report;
- investigate the issue;
- determine the impact;
- provide a resolution if applicable.

## Scope

This policy applies to:
- repository infrastructure;
- official tooling;
- automation scripts;
- website components;
- templates distributed by the project.
