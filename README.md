# PowerShield License (PSL) 1.0

Free. Protected. Yours.

PowerShield License is a permissive source-available software license designed
for developers who want:
- freedom to use and modify software;
- commercial usage support;
- required attribution;
- protection against harmful use.

| Feature | Supported |

| Modification | ✅ |
| Distribution | ✅ |
| Private Use | ✅ |
| Attribution Required | ✅ |

| OSI Approved | ❌ |
