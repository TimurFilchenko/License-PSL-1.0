# Philosophy

PowerShield License was created to balance two principles:

1. Software freedom
2. Responsible use of technology

Many permissive licenses prioritize freedom without constraints.
PSL introduces an additional ethical boundary to discourage harmful usage
while preserving broad usability.

## Core Ideas

- Developers should retain control over their work.
- Software should remain reusable and adaptable.
- Authors should be able to express ethical boundaries.
- Licensing should remain simple and readable.

## Position

PSL is not intended to replace existing licenses like MIT or Apache 2.0.
It is intended as an alternative for developers who want explicit ethical
restrictions without moving to restrictive proprietary models.
