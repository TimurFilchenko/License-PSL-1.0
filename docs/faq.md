# Frequently Asked Questions

## What is PowerShield License (PSL)?

PowerShield License (PSL 1.0) is a source-available software license designed to allow free use, modification, and distribution of software while including attribution requirements and ethical use restrictions.

## Is PSL an open source license?

No. PSL is not considered an open source license because it includes usage restrictions related to harmful activity.

## Can I use PSL in commercial projects?

Yes. Commercial use is allowed.

## Can I modify PSL-licensed software?

Yes. Modification is allowed as long as attribution and license terms are preserved.

## Do I need to include the license text?

Yes. The license notice must be included in all copies or substantial portions of the software.

## What does “LicenseRef-PSL-1.0” mean?

It is a custom SPDX identifier used to reference the PowerShield License in tooling that supports SPDX-style annotations.

## Can I relicense my project under PSL?

Yes, if you are the copyright holder of the project.
