# License Compatibility

This document describes how PowerShield License interacts with other licenses.

## Overview

PowerShield License is a source-available license with ethical use restrictions.

## Compatibility Table

| License | Commercial Use | Modification | Redistribution | Compatible with PSL |
|---|---|---|---|---|
| MIT | Yes | Yes | Yes | Partial |
| Apache 2.0 | Yes | Yes | Yes | Partial |
| BSD-3-Clause | Yes | Yes | Yes | Partial |
| GPLv3 | Yes | Yes | Yes | Partial |
| MPL 2.0 | Yes | Yes | Yes | Partial |
| Proprietary Licenses | Varies | Varies | Varies | No |

## Notes

Compatibility depends on interpretation of ethical restrictions and attribution
requirements. Users should evaluate legal compatibility for their specific use
case.
